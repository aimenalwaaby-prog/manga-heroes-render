# Manga Heroes redesign

- Replaced the Mihon-style five-item home shell with a Manga Heroes dashboard and six-destination navigation.
- Added a first-class AI destination in the bottom navigation using the existing Manga Heroes AI/profile/quests screen.
- Added a vivid default Manga Heroes color scheme while retaining the other selectable themes.
- Added a gradient/shimmer chapter download ribbon that appears between chapter content rows while a chapter is queued/downloading.
- Added a novel-source bridge that uses the same repository layer but a separate text-content pipeline and reader.
- Kept repository management and extension installation in the existing Browse flow.
- Added local profile/quest/AI access to the new visual hierarchy rather than hiding them in More.
