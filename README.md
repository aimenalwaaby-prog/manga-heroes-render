# Manga Heroes | مانجا هيروز

**نسخة Android عربية/إنجليزية للمانجا والمانهوا والويب تون**، مبنية كتفرع مميز من [Mihon](https://github.com/mihonapp/mihon). تحافظ على قارئ Mihon ومكتبته ومصادره وإضافاته وتنزيلاته ومصادره المحلية والتتبع والنسخ الاحتياطي والإعدادات، وتضيف هوية Manga Heroes ولوحة ملف وأهداف وقناة مساعدة بالذكاء الاصطناعي.

حزمة التطبيق المستقلة هي `app.mangaheroes`؛ لذلك لا تستبدل تثبيت Mihon ولا تشارك قاعدة بياناته تلقائيًا. يمكن نقل مكتبة القارئ عبر النسخ الاحتياطي والاستعادة في Mihon عند الحاجة.

## الميزات المُنفذة

- أيقونة Android تكيفية جديدة بطبقة شفافة، وحرف H وسيفين، مع نسخة أحادية اللون وخلفية متوافقة مع المشغلات الحديثة؛ والأيقونة المصدرية النهائية في `brand/manga-heroes-icon.png`.
- اسم وموارد واجهة للغتين العربية والإنجليزية، وألوان العلامة الزرقاء والحمراء والذهبية.
- ملف قارئ محلي يحفظ الاسم والأنواع المفضلة وعلامات إنجاز أهداف القراءة اليومية على الجهاز.
- اختيار العرض **العمودي/الأفقي** يحدّث تفضيل المكتبة الأصلي في Mihon مباشرة ويحفظه، بدلاً من حفظ اختيار شكلي منفصل.
- مدخل للإحصاءات القائمة في Mihon، ودليل محلي موجز لإضافة المجلدات وملفات الفصول.
- نظام روايات مستقل يقرأ تعريفات `novelSources` الآمنة من المستودعات، وينفذ البحث والفصول والقراءة النصية وحفظ موضع القراءة محليًا، مع رفض التعريفات غير الآمنة أو غير الصحيحة.
- مساعد اقتراحات يمر عبر خادم Manga Heroes مستقل على Render؛ الخادم يستخدم **مزود OpenRouter واحدًا فقط**، و**مفتاح المزوّد لا يدخل التطبيق أو APK**.

الأهداف اليومية اختيارية وتُعلّم يدويًا؛ ليست عدّادًا تلقائيًا موصولًا بأحداث القارئ. الملف والتفضيلات المحلية لا تتزامن بين الأجهزة. المجتمع العام وسير عمل الترجمة وربط توصيات الذكاء بفهرس مصادر حي ليست ضمن هذا الإصدار، ولا ندّعي اكتمالها.

## البناء

يتطلب المشروع JDK **21**، وAndroid SDK Platform **37.2**، وBuild Tools **36.0.0**، وNDK **29.0.14206865** (يمكن لـGradle تنزيل حزمة الأدوات تلقائيًا). لإنتاج APK موقّع يجب تجهيز `keystore.properties` محليًا ليشير إلى ملف JKS الخاص بك؛ **لا تضع ملف المفتاح أو كلمات المرور في مستودع عام**. أمر البناء:

```bash
MANGA_HEROES_AI_BASE_URL=https://your-host \
MANGA_HEROES_AI_TOKEN='your-gateway-token' \
./gradlew :app:assembleRelease
```

ناتج APK الموحّد: `app/build/outputs/apk/release/app-universal-release.apk`؛ ويُنتج Gradle أيضًا APKs منفصلة لمعمارية الجهاز. ويمكن البناء دون إعداد الخادم، لكن المساعد سيظهر بحالة غير مهيأة. لا نمرّر `OPENROUTER_API_KEY` إلى Gradle؛ يوضع هذا المفتاح على الخادم فقط. راجع [`server/README.md`](server/README.md).

## تشغيل خادم الذكاء الاصطناعي

انسخ `server/.env.example` إلى `server/.env` للتشغيل المحلي. النسخة المنشورة تستخدم خدمة Render مجانية على `https://manga-heroes-ai.onrender.com` مع الأسرار داخل Render فقط، ولا تُحفظ الأسرار في GitHub أو مجلد المشروع. رمز `MANGA_HEROES_AI_TOKEN` المشترك مضمّن في تطبيق العميل؛ استخدم مصادقة جلسات وحصصًا دائمة قبل التوزيع الواسع.

## التوقيع والخصوصية

APK الإصدار يُوقّع بشهادة إصدار محلية مستقلة. احتفظ بملف JKS وكلمات مروره بأمان: يلزم **المفتاح نفسه** لتحديث تثبيتات هذا الإصدار. الشهادة توقيع مطوّر ذاتي وليست شهادة ناشر تجاري أو اعتمادًا من Google Play. لا ترفع المفتاح أو بيانات توقيعه إلى GitHub.
